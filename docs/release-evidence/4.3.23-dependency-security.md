# Mastodon 4.3.23 dependency and security evidence

Generated on 2026-08-09 (Asia/Tokyo) from the Paon 4.3.23 compatibility
checkout. This evidence records commands and results; it is not by itself a
production admission decision.

## Updated dependency baseline

- Go minimum and the container builder are pinned to Go 1.25.12.
- `github.com/jackc/pgx/v5` is 5.9.2 and
  `github.com/russellhaering/goxmldsig` is 1.6.0. These replace versions with
  reachable findings reported by the first `govulncheck` run.
- The official OpenTelemetry Go SDK/exporters are 1.45.0.
- The frontend package manifest and Yarn lock are refreshed with the 4.3
  compatibility dependency changes. High and critical findings are cleared;
  one moderate development-server dependency finding remains as described
  below.
- The runtime image resolves to Debian 13.6 (`trixie-slim`) with FFmpeg
  `7:7.1.5-0+deb13u1` and libvips `8.16.1-1+deb13u1`.

## Release disposition

The Go, frontend high/critical, and fixable-container gates are clean. The one
remaining frontend finding is moderate and confined to the development-server
dependency chain; it should be updated through its parent packages when a
compatible uuid release is available rather than hidden with a transitive
major-version override. The 210 Debian high/critical findings without a current
fix still require an explicit base-image/package risk disposition and a rescan
when Debian publishes updates. Do not reinterpret `--ignore-unfixed` as a clean
full inventory or Yarn's severity bitmask as a high/critical finding.

Exporter credentials, environment values, request bodies, URLs, query text,
tokens, and collector payloads were not captured in this evidence.
