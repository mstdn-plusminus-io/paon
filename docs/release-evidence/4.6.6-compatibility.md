# Mastodon 4.6.6 compatibility evidence

Generated on 2026-08-31 (Asia/Tokyo) from Paon branch `feature/4.6.6` at
base commit `21dce105b0b055605aeaa5aff5d34f9a7b213d91`. The authoritative upstream
checkout was Mastodon tag `v4.6.6`, commit
`d74bbd9a3c64740433e016dfc936e83d710858f6`.

This document records local implementation and automated verification. It is
not evidence of a production-volume migration rehearsal, deployed topology,
live-provider acceptance, or human browser/accessibility acceptance.

## Declared quote-policy divergence

Paon retains Mastodon's REST fields, endpoints, PostgreSQL relations,
notifications, and FEP-044f object shapes, but deliberately removes the quote
permission gate. Valid `public`, `followers`, and `nobody` inputs normalize to
`public`; otherwise-visible local posts report automatic public approval; and
incoming local-target QuoteRequests are accepted after visibility, block,
domain-block, and suspension checks. Outgoing QuoteRequest/Accept/Reject
exchange remains enabled because a remote target server is authoritative.

## Implemented v4.6 surfaces

- Collections and FEP-7aa9: REST and `v1_alpha` routes, CRUD/items/revoke,
  pagination/scopes/limits, REST status/search/notification/report/admin
  surfaces, ActivityPub objects and activities, remote discovery/synchronizing,
  FeatureAuthorization verification, reach calculation, cleanup and repair,
  streaming/push, and retained-design UI.
- Profile and account entities: `/api/v1/profile`, image upload/delete and alt
  text, profile fields/settings, attribution domains, display limits, account
  feature policy hydration, and ActivityPub profile settings/images.
- Email subscriptions: anonymous confirmation/unsubscribe, MX and block checks,
  owner/admin controls, subscriber counts, resilient per-recipient Asynq
  delivery, image-bearing localized mail, cleanup, and account/global/role
  gates.
- Authentication and roles: role-required 2FA, invite approval bypass and
  email-management permission bits, collection limits, browser/API guards, and
  disable protection.
- REST/runtime: API level 11, annual report state/generate/schema 2/share,
  donation campaigns, entity field additions, notification supported types and
  fallback, custom-filter import/export, poll plus media, account-status
  `exclude_direct`, 10,000-character media descriptions, 40-character display
  names, FFmpeg `fps_mode`, and Meilisearch circuit breaking.
- Federation: multiple remote keypairs and rotation, Draft/RFC 9421/Linked Data
  verification, FEP-2c59 WebFinger backlink, FEP-3b86 activity intents,
  attachment duration, profile image descriptions, collection tags, follower
  synchronization guard, and remote HTML `lang` preservation.
- Frontend/operations: profile image editing, collections from account menus and
  status previews, annual-report sharing, overview homepage, migrated color
  scheme/contrast settings, vertical-language presentation, and pasted/dropped
  status URL quote discovery. `paon-admin vacuum media --keep-interacted`
  preserves cached media for statuses favourited, bookmarked, quoted, replied
  to, or reblogged by local accounts.
