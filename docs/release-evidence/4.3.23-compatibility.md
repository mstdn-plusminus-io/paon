The differential harness keeps Paon's quote fields as explicit Go-only JSON
pointers and fails if they disappear from Paon or unexpectedly appear in the
Rails response. Sign-in response bodies and instance image source URLs are the
only UI-design normalizations; their response status and protocol headers
remain compared. This preserves the requested design boundary without weakening
the surrounding API comparison.

## Production admission still required

The implementation is ready for acceptance, but the following release gates
require environment or human evidence that this checkout cannot manufacture:

- rehearse the phased migration on production-volume data, measuring locks,
  replica lag, disk headroom, rolling writers, and backup/restore across the
  OTP contract boundary;
- run actor, note, collection, and signature interoperability against a real
  remote Mastodon 4.3.23 instance;
- exercise desktop/mobile/touch/keyboard/screen-reader/reduced-motion browser
  flows and mail-client rendering for the retained Paon design;
- rehearse Redis Sentinel failover, worker restart, self-destruct, partial
  storage failure with real Swift/Azure targets, and Meilisearch-unavailable
  operation;
- approve or remediate every unresolved high/critical base-image finding, then
  rescan the exact release image.

The repository default Mastodon version must be changed to `4.3.23` only after
these acceptance items pass. Until then, code compatibility and production
release admission are deliberately reported separately.
