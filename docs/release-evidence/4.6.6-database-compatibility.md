## Data-migration behavior

The phased runner preserves the upstream behavior for the global default-theme
rewrite, per-user theme conversion, invite-approval bypass permission, and the
collection-item composite uniqueness migration. The latter deletes duplicate
rows only after a non-null duplicate would make the first upstream index
attempt fail; it then uses Mastodon's lowest-ID `DISTINCT ON` result, including
the same treatment of null-account groups. The featured-emoji foreign key is
installed `NOT VALID` in expand and validated before contract. The final marker
is withheld until the three superseded indexes are removed and the full schema
guard succeeds.

Production admission still requires a production-sized rehearsal that measures
locks, table rewrites, index build time, disk headroom, replica lag, backup and
restore, rollback fencing, and mixed-version writer behavior.
